### 1-6. "다시 시도" 버튼

#### 비포커스 상태 (기본)

| 속성 | 값 |
|------|----|
| 버튼 타입 | `UIButton.Configuration.filled()` |
| 배경색 | `DS.Colors.primary` (#3680FF) |
| 텍스트색 | `DS.Colors.textPrimary` (white) |
| 폰트 | `DS.Typography.cardTitle` = systemFont(size: 22, weight: .semibold) |
| contentInsets | `DS.ButtonInsets.cta` = top 14, leading 36, bottom 14, trailing 36 |
| 코너 반경 | `DS.Corner.button` = 16pt |
| cornerStyle | `.fixed` |
| topAnchor | (서브타이틀이 있으면) subtitleLabel.bottomAnchor + `DS.Spacing.lg` (40pt) / (없으면) titleLabel.bottomAnchor + `DS.Spacing.lg` (40pt) |
| centerX | container.centerX |
| shadow | 없음 (비포커스) |
| scale | 1.0 |
| border | 없음 (비포커스) |

#### 포커스 상태

`FocusEffect.applyBorder(to:focused:)` (DesignSystem.swift:202)를 그대로 사용한다.
이 함수가 적용하는 효과:

| 속성 | 포커스 시 값 | 비포커스 시 값 |
|------|-----------|------------|
| transform (scale) | CGAffineTransform(scaleX: 1.05, y: 1.05) | .identity |
| layer.borderColor | `DS.Colors.primary.cgColor` (#3680FF) | — |
| layer.borderWidth | 3pt | 0 |
| layer.shadowColor | `DS.Colors.primary.cgColor` (#3680FF) | — |
| layer.shadowOpacity | 0.6 | 0 |
| layer.shadowOffset | .zero | — |
| layer.shadowRadius | 20pt | — |

> 호출 위치: `didUpdateFocus(in:with:)` 내부, `coordinator.addCoordinatedAnimations` 블록 안에서 호출.
> `MyViewController.showEmptyState()`의 refreshBtn처럼 `UIFocusGuide` 없이 `canBecomeFocused`를 직접 `true`로 반환하는 UIButton 서브클래스 또는 오버라이드를 사용한다.

#### 포커스 이동 (오류 상태 뷰 표시 시점)

오류 상태 뷰가 addSubview된 직후:
1. `setNeedsFocusUpdate()` 호출
2. `updateFocusIfNeeded()` 호출
3. ViewController가 `preferredFocusEnvironments`를 오버라이드하여 "다시 시도" 버튼을 반환하거나,
   `UIFocusGuide`로 버튼으로 유도한다.

`MyViewController.showEmptyState()`에서 `refreshTapped`가 `loadFavorites()`를 호출하는 것과 동일한 패턴으로 구현한다.

### 1-7. 등장 / 소멸 애니메이션

기획서 §8-4 원칙에 따라 **별도 등장 애니메이션 없음**. 즉시(instant) 표시.

- 오류 상태 뷰 표시: `alpha = 1`, `isHidden = false` 즉시 설정
- 오류 상태 뷰 소멸("다시 시도" 탭 시): `removeFromSuperview()` 즉시 호출 후 스켈레톤 재표시

> 이유: `hideSkeleton()` 직후 오류 뷰가 등장하는 타이밍이므로 페이드 애니메이션이 겹치면 사용자가 혼란스럽다. `MyViewController.showEmptyState()`도 애니메이션 없이 즉시 표시한다.

## 2. 검색 빈 상태 + 범위 안내 (I-6, I-7) 디자인 명세

### 2-1. emptyLabel 2줄 구성

`SearchViewController`의 `emptyLabel`은 단일 `UILabel`에 `NSAttributedString`으로 두 줄을 구성한다.

#### 줄 1 — 결과 없음 안내 (주 문구)

| 속성 | 값 |
|------|----|
| 폰트 | `DS.Typography.subsection` = systemFont(size: 28, weight: .semibold) |
| 색상 | `DS.Colors.textSecondary` (#B4B4BC) |

#### 줄 2 — 검색 범위 안내 (보조 문구)

| 속성 | 값 |
|------|----|
| 폰트 | `DS.Typography.body` = systemFont(size: 20, weight: .regular) |
| 색상 | `DS.Colors.textTertiary` (#787880) |

#### emptyLabel 공통 설정

| 속성 | 값 |
|------|----|
| numberOfLines | 0 (현재 미설정이면 추가 필요) |
| textAlignment | `.center` |
| 최대 너비 | 명시적 제약 불필요 (기존 centerX/centerY 배치 유지) |

#### NSAttributedString 구성 방식

1번째 줄 attributedString:
- text: `"{검색어}"에 대한 결과가 없습니다`
- attributes: `.font` = `DS.Typography.subsection`, `.foregroundColor` = `DS.Colors.textSecondary`

개행 문자 `\n` 삽입 후 2번째 줄 attributedString:
- text: `인기 카테고리 상위 15개의 라이브 방송에서 검색한 결과입니다`
- attributes: `.font` = `DS.Typography.body`, `.foregroundColor` = `DS.Colors.textTertiary`

두 속성 문자열을 `NSMutableAttributedString`으로 이어붙여 `emptyLabel.attributedText`에 할당.
`emptyLabel.text`(plain text) 직접 할당은 사용하지 않는다.

#### 검색어 없음 상태 (기존 유지)

| 속성 | 값 |
|------|----|
| 표시 문구 | "검색어를 입력해 보세요" (1줄, 범위 안내 없음) |
| 폰트 | `DS.Typography.subsection` |
| 색상 | `DS.Colors.textSecondary` |

이 경우에는 plain text 또는 단일 줄 attributedString으로 설정한다.

### 2-3. 결과 그리드와의 배타 표시 규칙 (I-7)

모든 상태 전이에서 아래 두 조건이 동시에 충족되어야 한다.

| 상태 | `emptyLabel.isHidden` | `resultsCollectionView.isHidden` |
|------|----------------------|----------------------------------|
| 검색어 없음 (빈 문자열) | false (표시) | true (숨김) |
| 검색 결과 있음 | true (숨김) | false (표시) |
| 검색 결과 0건 | false (표시) | true (숨김) |

**규칙**: 두 뷰의 `isHidden`은 항상 반대값이어야 한다.
단일 헬퍼에서 두 값을 함께 설정해 누락을 방지한다.

## 3. 10-foot UI 원칙 체크리스트

tvOS는 시청 거리 약 3미터를 가정한 "10-foot UI" 환경이다.
이번 개선 항목에 적용되는 최소 기준을 명시한다.

### 3-1. 폰트 크기

| 역할 | 최소 크기 | 사용 토큰 | 통과 여부 |
|------|---------|---------|---------|
| 오류 타이틀 (1줄) | 28pt 이상 | `DS.Typography.subsection` (28pt) | 통과 |
| 오류 서브타이틀 / 조치 안내 | 20pt 이상 | `DS.Typography.body` (20pt) | 통과 |
| "다시 시도" 버튼 텍스트 | 20pt 이상 | `DS.Typography.cardTitle` (22pt) | 통과 |
| 검색 emptyLabel 1줄 | 28pt 이상 | `DS.Typography.subsection` (28pt) | 통과 |
| 검색 emptyLabel 2줄 (범위 안내) | 18pt 이상 | `DS.Typography.body` (20pt) | 통과 |
| 아이콘 (SF Symbol) | 80×80pt | 고정 80pt | 통과 |

### 3-2. 색상 대비

다크 배경(`DS.Colors.background` = #0A0A0C) 위에서의 대비비:

| 요소 | 색상 | 배경 대비 판정 |
|------|------|-------------|
| 오류 타이틀 | `DS.Colors.textPrimary` (white, #FFFFFF) | 매우 높음 (≈ 21:1) |
| 서브타이틀 | `DS.Colors.textSecondary` (#B4B4BC) | 충분 (≈ 8:1) |
| 범위 안내 2줄 | `DS.Colors.textTertiary` (#787880) | 최소 기준 이상 (≈ 4.5:1) |
| 아이콘 | `DS.Colors.textTertiary` (#787880) | 아이콘은 크기로 보완, 허용 |
| 버튼 배경 | `DS.Colors.primary` (#3680FF) | — |
| 버튼 텍스트 | `DS.Colors.textPrimary` (white) / primary 배경 | 충분 (≈ 5.5:1) |

### 3-3. 포커스 가시성

| 체크 항목 | 요구사항 | 구현 방법 |
|---------|---------|---------|
| "다시 시도" 버튼 포커스 표시 | 3미터 거리에서 포커스 상태가 명확히 구분되어야 함 | `FocusEffect.applyBorder` — 블루 보더 3pt + 블루 글로우 shadow radius 20pt |
| 버튼 scale 변화 | 포커스 시 약간 커져 선택 가능함을 암시 | scale 1.05 (FocusEffect.applyBorder) |
| 오류 뷰 표시 즉시 포커스 이동 | 사용자가 리모컨을 누르면 즉시 반응 가능 | `setNeedsFocusUpdate()` + `updateFocusIfNeeded()` |
| 탭 전환 후 포커스 복원 | 탭을 나갔다 돌아와도 오류 뷰 포커스 유지 | `preferredFocusEnvironments` 오버라이드 또는 `UIFocusGuide` |

### 3-4. 안전 영역 및 마진

| 항목 | 값 | 근거 |
|------|-----|------|
| 컨테이너 최대 너비 | 720pt | `MyViewController.showEmptyState()` 동일 |
| 컨테이너 배치 | view.centerX, view.centerY | 화면 정중앙 |
| 좌우 텍스트 여백 | 컨테이너 내부 (max 720pt) | TV 안전 영역 내 포함 |
| tvOS safe area | `safeAreaLayoutGuide` 사용 권장 | 기존 패턴 유지 |

### 3-5. 금지 사항

- 개발자 용어 (`err`, `.env`, `SOOP_ID`, `SOOPAPIError`, URL, HTTP 코드 등) 텍스트 노출 절대 금지
- 기술 스택 용어 (Swift, API, HTTP 등) 텍스트 노출 절대 금지
- 14pt 미만 폰트 사용 금지 (에러 상태 뷰에서)
- 단순 숫자 에러 코드 노출 금지

### 4-1. 오류 상태 뷰 — 하드코딩 금지 항목

코딩 에이전트는 아래 항목을 반드시 DS 토큰으로 처리해야 한다.
수치 직접 입력(magic number) 및 UIColor(red:green:blue:) 직접 호출은 금지.

| 항목 | 올바른 토큰 | 하드코딩 예시 (금지) |
|------|-----------|-------------------|
| 아이콘 tintColor | `DS.Colors.textTertiary` | `UIColor(red: 120/255, ...)` |
| 타이틀 색상 | `DS.Colors.textPrimary` | `UIColor.white` |
| 서브타이틀 색상 | `DS.Colors.textSecondary` | `UIColor(red: 180/255, ...)` |
| 버튼 배경색 | `DS.Colors.primary` | `UIColor(red: 54/255, ...)` 또는 `#3680FF` |
| 버튼 텍스트색 | `DS.Colors.textPrimary` | `UIColor.white` |
| 버튼 폰트 | `DS.Typography.cardTitle` | `UIFont.systemFont(ofSize: 22, ...)` |
| 타이틀 폰트 | `DS.Typography.subsection` | `UIFont.systemFont(ofSize: 28, ...)` |
| 서브타이틀 폰트 | `DS.Typography.body` | `UIFont.systemFont(ofSize: 20, ...)` |
| 버튼 코너 | `DS.Corner.button` | `16` 또는 `CGFloat(16)` |
| 버튼 insets | `DS.ButtonInsets.cta` | `NSDirectionalEdgeInsets(top: 14, ...)` |
| 아이콘 크기 | `80` (pt, 기획서 확정값 — 해당 토큰 없음, 아래 §4-4 참조) | `CGFloat(80)` 매직 넘버 |
| 아이콘 ↔ 타이틀 간격 | `DS.Spacing.md` (24pt) | `24` |
| 타이틀 ↔ 서브타이틀 간격 | `8` (pt, 기획서 확정값 — `DS.Spacing.xs`의 절반, 아래 §4-4 참조) | `8` |
| 서브타이틀 ↔ 버튼 간격 | `DS.Spacing.lg` (40pt) | `40` |
| 컨테이너 최대 너비 | `720` (pt, 기획서 확정값 — `MyViewController.showEmptyState()` 동일, 아래 §4-4 참조) | `720` |
| 포커스 효과 | `FocusEffect.applyBorder(to:focused:)` | 직접 layer.borderWidth = 3 등 |
| 포커스 보더 색상 | `FocusEffect.applyBorder` 내부에서 `DS.Colors.primary` 사용 | `UIColor.blue` 또는 직접 설정 |

### 4-2. 검색 emptyLabel — 하드코딩 금지 항목

| 항목 | 올바른 토큰 | 하드코딩 예시 (금지) |
|------|-----------|-------------------|
| 1줄 폰트 | `DS.Typography.subsection` | `UIFont.systemFont(ofSize: 28, ...)` |
| 1줄 색상 | `DS.Colors.textSecondary` | `UIColor(red: 180/255, ...)` |

### 4-3. 신규 디자인 토큰 추가 여부

이번 개선 범위에서 **신규 DS 토큰 추가는 필요 없다**.

- 아이콘 크기(80pt), 컨테이너 최대 너비(720pt), 타이틀/서브타이틀 간격(8pt)은
  `MyViewController.showEmptyState()`에서 이미 사용 중인 확정값이므로,
  DS enum에 추가하기보다 코드 주석으로 "MyViewController.showEmptyState()와 동일값" 명시로 충분하다.
- 해당 값들을 상수 `let`으로 각 메서드 내에 선언하는 것도 허용한다.

### 4-4. 토큰 없는 수치 — 명시적 상수화 기준

아래 3개 값은 DS enum에 없지만 여러 화면에서 공통 사용되므로,
코딩 에이전트는 인라인 magic number를 피하기 위해 각 구현부 상단에 `let` 상수로 명시한다.

| 상수명 (권장) | 값 | 의미 |
|-------------|-----|------|
| `errorIconSize: CGFloat` | 80 | 오류 상태 아이콘 너비/높이 |
| `errorContainerMaxWidth: CGFloat` | 720 | 오류 상태 컨테이너 최대 너비 |
| `errorTitleSubtitleGap: CGFloat` | 8 | 타이틀-서브타이틀 수직 간격 |

> 만약 이 값들이 앱 전역에서 반복 사용되는 경우, DS enum에 추가하는 것이 바람직하다.
> 단 이번 사이클에서는 오류 상태 뷰에서만 사용되므로 로컬 상수로 충분하다.
> DS에 추가한다면 위치는 `DS.Layout` enum 내에 추가한다:
>
> ```
> DS.Layout.errorIconSize: CGFloat = 80
> DS.Layout.errorContainerMaxWidth: CGFloat = 720
> ```
>
> `errorTitleSubtitleGap`은 패턴적으로 `DS.Spacing.xs / 2`이나,
> Spacing enum은 8pt 기반이므로 4pt 단위는 어울리지 않아 로컬 상수 권장.

## 5. 개선 항목별 디자인 결정 요약

### I-1 (홈/탐색 오류 뷰)
- 서브타이틀 없이 아이콘 + 타이틀 + 버튼 3요소만 사용 (단순화)
- 홈/탐색은 오류 원인이 명확히 네트워크이므로 서브타이틀 불필요
- `wifi.exclamationmark` SF Symbol — 네트워크 오류를 직관적으로 전달

### I-3 (MY 탭 오류 메시지)
- 서브타이틀 추가 (loginRequired vs. 네트워크 구분)
- `person.crop.circle.badge.exclamationmark` — 로그인 관련 아이콘
- 기존 `showEmptyState()` 패턴과 동일한 레이아웃 구조 유지 (일관성)

### I-6 (검색 범위 안내)
- NSAttributedString 2줄 구성으로 단일 UILabel 유지 (추가 뷰 불필요)
- 2줄을 별도 UILabel로 분리하지 않음 (I-7의 배타 표시 로직 단순화)

### I-7 (emptyLabel 겹침 방지)
- 단일 헬퍼 메서드에서 emptyLabel.isHidden + resultsCollectionView.isHidden 동시 설정
- 두 값이 항상 반대임을 코드 레벨에서 보장

### 포커스 처리
- `FocusEffect.applyBorder` 기존 함수 그대로 재사용 (신규 효과 함수 불필요)
- 포커스 이동: `setNeedsFocusUpdate()` + `updateFocusIfNeeded()` 패턴 (MyViewController 동일)

### 신규 토큰
- 신규 DS 토큰 추가 없음 (기존 토큰으로 완전히 커버)
- 아이콘 크기(80pt), 컨테이너 최대 너비(720pt)는 로컬 상수로 처리
