## 3. 기획과 다르게 구현된 사항 (검수에서 타당성 승인됨)

1. **I-3 오류 유형 분기**: 기획서가 가정한 `SOOPAPIError.loginRequired` 케이스가 실제 코드에 없어
   (실존 케이스: invalidURL/invalidResponse/decodingFailed/streamUnavailable/notLive/adultVerificationRequired),
   **AuthTicket 쿠키 유무**로 인증/네트워크 오류를 구분. 검수 1차에서 타당한 대체 구현으로 승인.
2. **I-4 보강**: UITabBarController의 탭 콘텐츠 뷰가 viewDidLoad 이후에 붙는 특성상
   `addSubview` 직후 1회 호출만으로는 부족하여 `viewDidLayoutSubviews`에서 재호출 추가.

## 4. 추가로 확인해야 할 사항

### 필수 (배포 전)
1. **실기기/시뮬레이터 실측 테스트 미수행** — 본 사이클의 테스트는 코드 추적 기반 **가상 테스트**다.
   실제 Apple TV(또는 시뮬레이터)에서 다음을 확인할 것:
   - 네트워크 차단(Wi-Fi 끔) 상태에서 홈/탐색/MY 진입 → 오류 뷰 + 리모컨 포커스가 "다시 시도" 버튼에 실제로 가는지
   - 재시도 버튼 클릭 → 정상 복구
   - 검색 탭: 네트워크 차단 상태 진입 → 복구 후 검색 → 자동 재로드와 결과 복원
2. **커밋 미수행** — 변경분은 작업 트리에만 있다. 검토 후 커밋 필요.
   (consulting/, inspection/ 폴더도 untracked 상태 — 함께 커밋할지 결정 필요)

### 권장 (차기 사이클 후보)
3. **검색 풀 커버리지 한계** — 여전히 상위 15개 카테고리만 검색 (전체 500+ 중 ~3%).
   I-6의 범위 안내로 사용자 혼란은 완화했으나, 근본 해결은 SOOP 검색 API 직접 연동 필요.
4. **`group.notify` 클로저 일부 `[weak self]` 미선언** — 기존 코드 전반의 동일 패턴으로
   실질적 retain cycle은 아님(테스트 보고서 참고사항). 일괄 정리는 별도 리팩터링으로.
5. **이전 사이클 잔여 Low 이슈(#L1~#L5)** — 코드 품질 항목, 사용성 영향 없음 (test-report-v2-fixed.md 참조).
6. **CLAUDE.md 갱신 권장** — 현재 CLAUDE.md의 아키텍처 설명이 3-탭 구조 기준인데
   실제 앱은 4-탭(홈/탐색/검색/MY) + DesignSystem 구조로 진화함. 문서 현행화 필요.
