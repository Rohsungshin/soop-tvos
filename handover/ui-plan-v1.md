# SOOP tvOS App UI/UX 개선 기획서 v1

> 작성일: 2026-05-29
> 대상: tvOS 17.0+ Apple TV 네이티브 앱 (UIKit, Swift 5)
> 입력: Siri Remote (방향키 + Select/Menu/Play-Pause)

## 1. 현재 UI 분석 및 문제점

### 1.1 공통 (모든 화면)

| # | 문제점 | 영향 |
|---|------|------|
| C1 | 헤더에 이모지(📺 LIVE / ⭐️ 즐겨찾기) + 56pt bold 사용. Apple TV 네이티브 앱(Apple TV+, Netflix 등)은 이모지를 거의 쓰지 않음 | 비전문적 인상, 톤 부조화 |
| C2 | 새로고침 버튼이 우측 상단 별도 UIButton으로 노출. 리모컨 포커스가 상단까지 올라가야 닿음 → 상하 이동 거리가 길다 | 포커스 동선 비효율 |
| C3 | 모든 화면이 단색 검정(`.black`) 배경. 깊이감/계층감 없음 | 모던 감 부족 |
| C4 | `statusLabel`이 단순 텍스트("불러오는 중..."). 로딩 시 빈 화면 → 사용자는 앱이 멈춘 것으로 오해 가능 | 체감 성능 ↓ |
| C5 | 에러 UI가 본문 텍스트로만 표시. 재시도 방법이 "Play/Pause로 새로고침" 텍스트 안내뿐 | 발견성 ↓ |
| C6 | 셀 포커스 효과가 `scale 1.1 + white border 4~5pt`로 동일. tvOS 표준 parallax/floating 효과가 빠져 평면적 | 입체감 부족 |
| C7 | 폰트가 전부 `systemFont` 동일 패밀리. 카드 내 정보 위계(제목 > BJ > 시청자수)가 약함 | 정보 스캐닝 ↓ |
| C8 | 이미지 로딩 시 placeholder가 단색 회색. 스켈레톤 / blur 미처리 | 로딩 거칠어 보임 |

### 1.2 LiveCategoriesViewController

- L1. **카드 시청자수 배지가 좌상단**(빨강 박스 + 검정 텍스트 영역에 흰 글자). 컬러가 강해 시선이 시청자수에 먼저 가지만, 정작 중요한 건 카테고리 이름.
- L2. **이미지 위 80pt 검정 오버레이 + 가운데 정렬 22pt 굵은 흰 글자**. 텍스트가 카드 하단을 너무 압도함 → 카테고리 썸네일이 잘 안 보임.
- L3. **5열 × 카드 320×240 = 1840pt 너비** + sectionInset 80×2 → 1920 화면에 약간 좌우 여유. 모자라지 않지만, 카드가 정사각형에 가까워 카테고리 비주얼이 잘려 보임.
- L4. 카테고리 이름이 2줄 가운데 정렬 → 일부 카테고리("리그 오브 레전드", "버추얼 스트리머" 등 긴 이름)는 잘리거나 작아 보임.

### 1.3 LiveListViewController

- B1. **썸네일 종횡비 380:213 ≈ 16:9**. 좋음. 하지만 **liveBadge + viewerLabel이 둘 다 상단**에 같이 떠 있음 → 시각 무게가 위로 쏠림.
- B2. `liveBadge`가 모든 셀에 항상 표시됨 (라이브 리스트이므로 당연히 모두 LIVE). 정보 중복 → 셀에서 빼고 헤더에 한 번만 표시하는 게 나음.
- B3. 제목 18pt semibold, BJ 14pt lightGray → 폰트 크기 차가 적어 위계 약함.
- B4. 카드 하단 정보 영역에 **상단 패딩 10pt, 하단 패딩 없음** → BJ 이름이 셀 하단 가장자리에 너무 가까움.
- B5. 시청자수가 흰글자 + 검정 반투명 박스(우상단). LIVE 배지(빨강)와 색상 균형 맞지만 두 배지 사이 간격 없이 양 끝에 배치되어 시각적 긴장감 부족.
- B6. **로딩 시 alert로 "방송 연결 중..." 표시 → 모달이 화면을 가림**. tvOS 네이티브 패턴 아님 (보통 인라인 spinner를 셀에 표시).

### 1.4 ExploreViewController

- E1. **완전 placeholder** ("준비 중입니다") → 탭으로서 가치 없음.
- E2. 핵심 사용 시나리오(검색, 추천, 인기) 모두 미구현.

### 1.5 MyViewController

- M1. **즐겨찾기 빈 상태 텍스트가 안내 뿐** → 시각적 가이드 없음. 신규 사용자는 어떻게 즐겨찾기를 추가하는지 모름.
- M2. **라이브/오프라인 BJ 시각 차별화가 약함**. 오프라인은 단지 alpha 0.7/0.5 + 검정 반투명 오버레이 0.55. 멀리서 TV로 봤을 때 구분 어려움.
- M3. **오프라인 BJ 클릭 시 alert** → 화면 끊김. 차라리 셀을 포커스 불가(`canBecomeFocused = false`) 처리하거나, 셀 자체에 "방송 시작 알림" 같은 액션을 둘 수 있음.
- M4. 카드 상단 이미지가 정사각형 200pt → BJ 프로필이지만 프레임이 카드 폭(320)보다 작아 좌우 여백 확보 안 됨.
- M5. 라이브 BJ 정렬이 없음 — 라이브 중인 BJ가 오프라인과 섞여 그리드에 무작위 배치되면 사용자는 라이브를 찾기 힘듦.

### 1.6 PlayerViewController

- P1. **연결 중 상태가 빈 검정 화면 + "스트림 연결 중..." 텍스트**. BJ 썸네일/제목 표시 없음 → 사용자는 어떤 방송이 로딩 중인지 헷갈림.
- P2. **해상도 라벨이 항상 상단 우측 노출**(`alpha = 1` 유지) → 영상 시청 시 방해.
- P3. fallback 발생 시 라벨에 "FALLBACK" 표시 → 사용자에겐 의미 없는 정보.
- P4. AVPlayerViewController의 기본 컨트롤만 사용. 채팅, 방송 정보(제목/시청자수/방송시간) 오버레이 부재.

### 2.4 포커스 효과 (tvOS 표준 기반)

기존: `scale 1.1 + white border` 단일 패턴.
신규:

```swift
// 포커스 상태
transform = CGAffineTransform(scaleX: 1.08, y: 1.08)
contentView.layer.borderColor = UIColor(red: 0.21, green: 0.50, blue: 1.0, alpha: 1).cgColor // soopBlue
contentView.layer.borderWidth = 0
// + 그림자
layer.shadowColor = UIColor.black.cgColor
layer.shadowOpacity = 0.6
layer.shadowOffset = CGSize(width: 0, height: 16)
layer.shadowRadius = 24
// + 미세한 상단 발광 (브랜드 색)
layer.shadowPath = nil
```

- **scale 1.08** (기존 1.10보다 약간 차분)
- **borderWidth 0** → 카드가 깔끔. 대신 4-side 그림자로 부유감.
- **그림자 24pt blur + 16pt offset-y** → 카드가 살짝 떠 있는 느낌.
- **포커스 진입 애니메이션 0.35s spring** (`coordinator.addCoordinatedAnimations` 안에서 처리하면 tvOS 코디네이터 타이밍에 동기화됨).

> 추가: 큰 썸네일을 가진 카드(LiveBroadcast)는 tvOS 표준 `UIImageView.adjustsImageWhenAncestorFocused = true`를 사용하면 시스템 parallax 효과가 자동 적용된다. 단, 이를 쓰려면 imageView를 `contentView`가 아닌 `focusedFrameGuide`에 맞춰 배치해야 함.

## 3. 화면별 상세 기획

### 3.1 RootTabBarController

**현재**: 3탭 (LIVE / 탐색 / MY).
**개선**:

- **탭바 스타일**: tvOS 17의 표준 탭바 사용. 텍스트만으로 충분 (이모지 제거).
- **순서 재정렬**: `HOME` / `LIVE` / `탐색` / `MY` — HOME 탭을 신규 추가하고 기본 진입 탭으로 사용.
- **선택된 탭**: SOOP 브랜드 빨강(`#F23C3C`) 언더라인 + 흰 텍스트.
- **비선택 탭**: `text.secondary` (#B4B4BC).
- **앱 진입 시 기본 탭**: `HOME` (즐겨찾기 + 인기 카테고리 + 최근 시청 한 화면에 요약).

```swift
let homeNav = UINavigationController(rootViewController: HomeViewController())
homeNav.tabBarItem = UITabBarItem(title: "HOME", image: nil, tag: 0)

// 폰트 통일
UITabBarItem.appearance().setTitleTextAttributes([
    .font: UIFont.systemFont(ofSize: 30, weight: .semibold)
], for: .normal)
```

### 3.2 LiveCategoriesViewController

#### 레이아웃

| 항목 | 기존 | 변경 |
|---|---|---|
| 카드 사이즈 | 320 × 240 | **300 × 200** (16:10 비율로 가로 강조) |
| 컬럼 수 | 5 | **6** (300 × 6 + 24 × 5 + 64 × 2 = 2048... 1920 화면엔 320×6 무리. 따라서 **카드 264 × 176, 6열**도 고려. **최종: 카드 296 × 198, 5열 유지하되 좌우 여백을 60→72로 늘림**) |
| sectionInset | (40, 80, 80, 80) | **(32, 72, 72, 72)** |
| interitem spacing | 30 | **24** |
| line spacing | 40 | **32** |

> 최종: **5열, 카드 296 × 198**. 296 × 5 + 24 × 4 + 72 × 2 = 1480 + 96 + 144 = 1720pt. 1920에 남는 200pt는 좌우 여백 추가(각 100). 또는 카드를 308pt로 키워서 308 × 5 + 24 × 4 + 64 × 2 = 1540 + 96 + 128 = 1764pt. **선택: 카드 320 × 220, 5열 유지, 좌우 inset 64**. 320 × 5 + 24 × 4 + 64 × 2 = 1600 + 96 + 128 = 1824pt. 화면 1920에 여유 96pt → 좌우 추가 48pt씩 inset 처리.

**최종 레이아웃**:
```
itemSize = CGSize(width: 320, height: 220)  // 기존 240 → 220 (가로 강조)
minimumInteritemSpacing = 24
minimumLineSpacing = 32
sectionInset = UIEdgeInsets(top: 32, left: 64, bottom: 72, right: 64)
```

#### 헤더 영역 (기존 56pt → 신규)

```
┌──────────────────────────────────────────────────────────┐
│  LIVE                                                    │
│  실시간 인기 카테고리                                      │
└──────────────────────────────────────────────────────────┘
```

- 상단 라인: "LIVE" — 64pt bold, 색 `#FFFFFF`
- 하단 라인: "실시간 인기 카테고리" — 20pt regular, 색 `#B4B4BC`
- 새로고침 버튼 제거. 대신 **Play/Pause 키 안내**를 푸터(셀 하단 24pt 폰트)로 작게 표시. 또한 **빈 첫 셀 위치에 "↻ 새로고침" 셀**을 두는 것도 가능 (옵션).

#### 카드 (CategoryCell) 재설계

기존: 이미지 풀필 + 하단 80pt 검정 오버레이 + 가운데 정렬 텍스트.
신규:

```
┌─────────────────────────┐  카드 320 × 220
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  ← 이미지 영역 320 × 170 (16:8.5)
│ ▓ 카테고리 일러스트     │
│ ▓                       │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
├─────────────────────────┤
│  카테고리명             │  ← 22pt semibold, 좌정렬, 1줄
│  3.2만명 시청 중        │  ← 16pt medium, #FFC300 점 + 흰 글자
└─────────────────────────┘
```

- 이미지 영역: contentView 상단 0부터 170pt 까지. 모서리는 카드 상단만 18pt 라운딩.
- 정보 영역: 50pt 높이. 패딩 (좌16, 우16, 상8, 하10).
- 카테고리명: 22pt `.semibold`, 흰색, 1줄 truncating.
- 시청자수: `● 3.2만명` 형태. `●`은 `#FFC300` 12pt, 텍스트는 `#FFFFFF` 16pt `.medium`.
- 시청자수 0일 때는 행 자체를 숨김(`isHidden = true`).
- **빨간 배지 박스 제거** — 시청자수는 정보일 뿐 강조할 필요 없음. LIVE는 카테고리가 아닌 방송에 붙이는 게 자연스럽다.

#### 포커스 효과

- 그림자: opacity 0.7, offset (0, 18), radius 28.
- scale 1.06.
- 이미지 위에 살짝 어두운 → 밝아지는 그라데이션 (focused 시 brightness +5%).
- 보더 0 (없음).

### 3.3 LiveListViewController

#### 레이아웃

| 항목 | 기존 | 변경 |
|---|---|---|
| 카드 사이즈 | 380 × 290 | **400 × 282** |
| 컬럼 수 | 4 | **4 유지** |
| sectionInset | (40, 80, 80, 80) | **(32, 64, 72, 64)** |
| interitem spacing | 30 | **24** |
| line spacing | 40 | **40 유지** |

400 × 4 + 24 × 3 + 64 × 2 = 1600 + 72 + 128 = 1800pt. 화면 1920에 양옆 60pt 여유. 카드 내 이미지: 400 × 225 (16:9 정확히).

#### 헤더

```
┌──────────────────────────────────────────────────────────┐
│  ← 리그 오브 레전드                                       │
│  127개 방송 진행 중                                       │
└──────────────────────────────────────────────────────────┘
```

- 상단: "← {카테고리명}" — 48pt `.bold` (기존 56pt → 48pt로 축소, 카테고리 헤더 위계 명확화).
- 하단: "{n}개 방송 진행 중" — 18pt `.regular`, `#B4B4BC`.
- 좌측에 `←` (back hint, 18pt) — 실제로는 메뉴 키로 돌아가지만 시각적 단서.

#### 카드 (LiveBroadcastCell) 재설계

```
┌─────────────────────────────────────────┐  카드 400 × 282

### 3.4 ExploreViewController (재설계)

탭 가치: **검색 + 인기 + 추천**. 한 화면에 섹션별로 묶어 스크롤.

#### 레이아웃 (수직 스크롤, 섹션별 가로 캐러셀)

```

│  탐색                                                     │
│  무엇을 보고 싶으세요?                                    │

│  [🔍  검색하기                                         ]  │  ← 큰 검색 진입 셀

│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐                              │  ← 가로 캐러셀 (380 × 213 카드)
│  └──┘ └──┘ └──┘ └──┘ └──┘                              │
├──────────────────────────────────────────────────────────┤
│  인기 카테고리                                             │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐                              │  ← 가로 캐러셀 (240 × 160 카드)
│  └──┘ └──┘ └──┘ └──┘ └──┘                              │
├──────────────────────────────────────────────────────────┤
│  최근 시청한 방송                                          │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐                                   │
│  └──┘ └──┘ └──┘ └──┘                                   │

- 구조: `UITableView` (수직) + 각 셀이 가로 `UICollectionView` (캐러셀).
- 섹션 헤더: 28pt `.semibold` 흰색, 좌측 64pt 정렬.
- 캐러셀 항목 간 spacing 24pt, 카드 좌우 첫/끝 inset 64pt.

#### 1) 검색 진입 셀

- 높이 120pt, 좌우 패딩 64.
- 배경 `#141418`, 라운드 18pt.
- 좌측 36pt `🔍` (실제 구현 시 SF Symbol `magnifyingglass`로 대체), 우측 "검색하기 — BJ 닉네임/방송 제목" 24pt regular 흰색.
- 포커스 시 보더 `#3680FF` 3pt + scale 1.03.
- Select 누르면 **검색 화면 push** (구현: `SearchViewController`).

#### 2) 인기 방송 캐러셀

- 데이터 소스: `fetchBroadcasts(byCategory: "00000000")` 형태로 전체 인기 방송 (실제 SOOP `categoryContentsList` API에서 cate_no를 빈 값/전체로 쿼리하면 인기 방송 반환 가능. 안 되면 인기 카테고리 N개를 순회해 시청자수 상위 20개 머지).
- 카드: LiveBroadcastCell 재활용 (380 × 245, 썸네일 비율 16:9).

#### 3) 인기 카테고리 캐러셀

- 데이터: `fetchCategories()` 후 시청자수 내림차순 상위 12개.
- 카드: 240 × 160 (CategoryCell 미니 변종).

#### 4) 최근 시청한 방송

- `UserDefaults`에 최근 본 broadNo+bjId+timestamp 10개 저장.
- 빈 경우 섹션 자체 숨김.

#### 검색 화면 (SearchViewController, 신규)

- tvOS 표준 `UISearchController` + 가상 키보드 사용.
- 결과: BJ 닉네임 매칭 / 방송 제목 매칭 두 섹션.
- API: SOOP `search` 엔드포인트 (`searchapi.sooplive.com/api/v0/search` 류) — 구현 시 `SOOPAPIClient`에 `search(query:)` 추가 필요.

- **FALLBACK 라벨 문구 변경**: "FALLBACK" → "안정 모드" (한글, 사용자 친화적).

## 4. 신규 기능 제안

### 4.1 HOME 탭 (신규, 최우선)

앱 첫 진입 시 보이는 요약 화면. Explore와 비슷한 구조이되 사용자 개인화에 초점:

- 섹션 1: **지금 방송 중인 즐겨찾기 BJ** (가로 캐러셀, 큰 카드)
- 섹션 2: **최근 시청한 방송** (가로 캐러셀)
- 섹션 3: **인기 카테고리 TOP 6** (가로 캐러셀)

즐겨찾기 미설정 / 데이터 없는 사용자에게도 인기 카테고리는 항상 보임 → 첫 인상에 콘텐츠가 풍부해 보임.

### 4.2 로딩 스켈레톤

`statusLabel` 텍스트 대신 카드 모양 placeholder 그리드:
- 회색 `#1C1C20` 카드 N개를 미리 그리고 shimmer 애니메이션 (0.8초 주기 좌→우 그라데이션).
- 데이터 도착 시 fade-in으로 실제 카드 교체.

### 4.3 이미지 메모리/디스크 캐시

현재: 매번 `URLSession.shared.dataTask`로 다운로드. 카드 재사용 시 깜빡임.
개선: `NSCache<NSURL, UIImage>` 메모리 캐시 + `URLCache.shared` 디스크 캐시 활용. 작은 유틸 클래스 `ImageLoader` 신설.

### 4.4 최근 시청 기록 저장

`UserDefaults`에 최근 본 broadNo+bjId+title+thumbnailURL+timestamp 최대 20개 (FIFO). HOME/Explore에 사용.

### 4.5 시청자수 자동 갱신

LIVE 카테고리/리스트 화면에서 30초마다 백그라운드 fetch → 시청자수만 셀에 patch 업데이트 (전체 reload 금지).

### 4.6 Apple TV Top Shelf (선택)

tvOS의 Top Shelf 확장으로, 홈 화면에서 앱 아이콘에 호버 시 "지금 방송 중인 즐겨찾기 BJ" 미리보기 노출. 데이터 소스를 공유 `App Group` 컨테이너에 캐싱.

### 4.7 검색 (Explore 내 진입점)

`UISearchController` + tvOS 가상 키보드. SOOP search API 추가 필요.

### 4.8 에러 토스트 컴포넌트

화면 하단 가운데에 1.5초 표시 후 자동 사라짐. iOS의 표준 토스트와 유사. 모달 alert를 대체.
